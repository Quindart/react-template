# City GRDP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `/city` route with an interactive Three.js visualization of 2025 estimated GRDP growth in six Vietnamese centrally governed cities.

**Architecture:** Register the route under the existing authenticated workspace layout and add a sidebar link. Keep data and labels in HTML; lazy-load a client-only Leaflet street map with Three.js city skylines and retain a readable fallback.

**Tech Stack:** React Router Framework Mode, React, TypeScript, Leaflet, Three.js, Tailwind CSS.

**Spec:** `docs/superpowers/specs/2026-10-24-city-grdp-design.md`

## Global Constraints

- Values represent estimated 2025 GRDP growth for six centrally governed cities.
- Every value remains readable without WebGL.
- Leaflet and Three.js initialize only after client mount; respect reduced motion, show map tile attribution, and dispose resources.
- Include a direct source link and disclose that the values are estimates.

## Review Focus

- SSR does not construct Three.js or access browser globals.
- Selection works by both 3D marker and accessible HTML button.
- WebGL failure retains all six data points.
- City positions remain inside the scene at mobile widths.
- Copy distinguishes GRDP growth from national GDP and shows estimate/source context.
